# 守秘人檔案櫃

由 AI 擔任守秘人（KP）的《克蘇魯的呼喚》單人跑團。你扮演一名調查員，用自己的話描述行動，AI 負責敘述世界、扮演 NPC、裁定規則。

**開始遊玩：https://scp600.github.io/COC-keeper/**

不用安裝，用電腦或手機的瀏覽器打開就能玩。一場大約 60 到 90 分鐘。

## 開始之前：設定守秘人

這個遊戲由你自己選的 AI 模型主持，所以需要一把你自己的 API 金鑰。

1. 打開網站，按右上角的「設定」。
2. 在「守秘人模型」選一家服務：Google Gemini、Claude API，或相容 OpenAI 介面的端點（例如 OpenRouter）。
3. 貼上你在該服務申請的 API 金鑰，按「測試連線」確認能通。

金鑰只存在你的瀏覽器裡，只會送給你選的那家服務。費用由你的金鑰支付，建議先在該服務的後台設用量上限。

## 怎麼玩

### 1. 從檔案櫃抽一份檔案

每份檔案是一個獨立的劇本，進度各自保存。

| 檔案 | 背景 | 類型 |
|---|---|---|
| 退潮街九號 | 1924 年，美國新英格蘭的港市 | 凶宅調查，遊戲內有三天期限 |
| 末班車之後 | 現代，台灣東北角 | 尋人與限時逃脫，從下午到午夜 |

### 2. 建立調查員

- 取名字、選職業。職業決定你擅長的八項技能和隨身物品。
- 擲屬性。最多擲三次，以最後一次為準。
- 把 70、60、60、50、50、50、40、40 分配給八項本職技能，再選最多四項興趣技能各加 20。
- 建好的調查員會收進首頁的「調查員名冊」，之後開同年代的劇本可以直接選用。

### 3. 選擇玩法

- **自由模式**：沒有任何選項。你完全用自己的話描述要做什麼、說什麼。
- **引導模式**：守秘人每次會附上三個方向模糊的行動提示，你也可以不理它們，照樣自己寫。

遊戲中隨時可以在「設定」切換。

### 4. 行動

在輸入框寫下調查員的行動或對話，例如「檢查地窖的牆」「問房東上一任房客的事」。守秘人會敘述結果。

- 沒有風險的行動會直接成功。
- 有風險的行動，守秘人會要求你擲骰。

## 規則速覽

**技能檢定**：擲一顆百面骰，結果小於或等於你的技能值就是成功。骰子由程式真實擲出，守秘人不能更改結果。

| 結果 | 條件 |
|---|---|
| 大成功 | 擲出 1 |
| 極難成功 | 不超過技能值的五分之一 |
| 困難成功 | 不超過技能值的一半 |
| 成功 | 不超過技能值 |
| 失敗 | 超過技能值 |
| 大失敗 | 擲出 100；技能值低於 50 時，96 以上都算 |

- **獎勵骰與懲罰骰**：情況有利或不利時，會多擲十位數的骰子，取較好或較差的那一顆。
- **孤注一擲**：檢定失敗後可以選擇再擲一次。如果又失敗，後果會比原本更嚴重。
- **生命**：受傷會扣生命，歸零時調查員倒下。
- **理智**：遇到無法理解的事要做理智檢定，失敗會失去理智。單次失去 5 點以上可能陷入暫時性瘋狂；理智歸零，調查員永久瘋狂。
- **時間**：行動、交通、查資料都會消耗遊戲內的時間。每個劇本都有期限，世界不會等你。

## 畫面上有什麼

- **調查員面板**（右側）：生命、理智、幸運、屬性、技能。
- **隨身物品**：以圖示顯示，現金會隨花費增減。
- **調查筆記**：取得的線索會自動記下，點開可以一則一則翻閱。
- **觀察面板**：顯示目前使用的模型和 token 用量。
- **設定**（右上角）：引導模式、氛圍音效與音量、骰子動畫與音效、守秘人模型。
- **檔案櫃**（左上角）：隨時回到首頁，進度會保留。

## 幾個提醒

- **選擇有後果。** 失敗就是失敗，調查員可能受傷、發瘋或死亡。
- **線索不會自己送上門。** 守秘人只描述你看到和聽到的事實，推理要靠你自己。
- **NPC 有自己的立場。** 他們會隱瞞、說謊、開條件。
- **有五種結局。** 結束後可以選擇「揭曉真相」，看完整的來龍去脈，以及你找到和錯過了哪些線索。
- **進度只存在這個瀏覽器。** 換裝置或清除瀏覽資料，存檔和調查員名冊都會消失。
